# 데이터 가정 (팀 결정 사항)

원본 `data/raw/stations.xlsx`(교수님 제공)는 수정하지 않는다. 원본에 없는 정보는 이 폴더의 파일로 보완한다.

| 파일 | 내용 | 근거 |
|---|---|---|
| line_stations.csv | 노선별 역 순서 (1·6호선은 순환) | 원본에 노선 열이 없어 노선도를 보고 작성, 원본 139개 구간과 대조 완료 |
| lines.csv | 순환선 여부 | 노선도 |
| transfers.csv | 환승역 35개, 환승 1회당 300초 | 팀 결정 (모든 환승역 동일) |
| station_names.csv | 역 이름 (한국어·영어) | 서울 실제 역명을 노선별로 빌려 배치. 실제 위치·순서와 무관한 가상 배치 |

- 모든 구간은 양방향이며, 두 방향의 시간·거리·비용이 같다고 가정한다 (원본에 방향 정보 없음).
- 시간 단위는 초, 거리는 미터, 비용은 원 (원본 열 이름 기준).
- 경로 비용은 구간 비용의 합으로 표시한다. 실제 요금 규칙은 적용하지 않는다.
- 역 번호 앞자리로 노선을 추정하지 않는다 (8개 구간에서 틀림). 노선은 항상 line_stations.csv 기준.
